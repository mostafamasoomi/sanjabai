# Product Contract for Multiai Aurora

## 1. User Segments

### 1.1. Consumer (کاربر عمومی)
- **Primary Goal:** Daily tasks like chat, writing, summarization, translation.
- **Characteristics:** Prefers simple, intuitive UI. Averse to technical details (API keys, advanced model settings).
- **Priorities:** Ease of use, fluid chat experience, transparent pricing, access to common models.
- **Role:** Primary initial and non-technical user base.

### 1.2. Developer (توسعه‌دهنده)
- **Primary Goal:** Integrate Multiai into their own applications, bots, or services via API.
- **Characteristics:** Requires comprehensive API documentation, SDKs (if available), API key management, request logs, Playground tools.
- **Priorities:** API stability, response speed, model variety, easy management of API keys and rate limits.
- **Role:** Building and extending AI-powered products and services.

### 1.3. Team (تیم/سازمان)
- **Primary Goal:** Collaborative use of Multiai within a team or organization, centralized user and cost management.
- **Characteristics:** Needs user management (invite, remove), team usage reporting, budget controls, access control.
- **Priorities:** Data security, collaboration features, dedicated support, invoicing and accounting capabilities.
- **Role:** Companies, startups, and larger organizations.
